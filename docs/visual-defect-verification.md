# Visual defect repair and verification

Date: 9 November 2026. Tested implementation: the editorial refactor in this checkout, using the Django preview and Chromium-based in-app browser. This report supersedes the game-oriented requirements/status in `field-guide-redesign.md`.

## Verification scope

Both themes were tested at **360×800, 390×844, 768×1024, 1024×768, 1366×650, 1440×900, and 1920×1080**. Heights other than the specifically requested 650px were selected for representative phone/tablet/desktop viewports.

The 14-case matrix inspected rendered DOM geometry, computed colors, removed elements, header and anchor offsets, project containment, status-chip bounds, studio controls, and certificate image dimensions. Screenshots were visually sampled at desktop and narrow mobile widths, including the hero, map, milestones and work section. This is not a claim of manual screenshot inspection of every pixel at all 14 sizes or a complete WCAG conformance audit.

All six work images loaded: five existing Huawei certificate records and the Saudi Cast image. The older local database did not have Huawei's certificate relationships populated, so those five existing records were attached **only in the temporary QA database**. The six-stop map also used a temporary QA-only path. No production content was changed for testing.

## Automated contrast results

Measured text uses rendered foreground color and nearest opaque ancestor background, WCAG sRGB linearization and relative luminance. Threshold: 4.5:1 body; 3:1 large text. Controls use the stronger of border-versus-surrounding-surface or fill-versus-surrounding-surface, threshold 3:1. Disabled controls, image text, illustration pixels, OS-native popup menus and non-rendered dialogs are not a general conformance certification. Artwork is decorative and not counted as text.

| Theme | Lowest text ratio | Lowest control-boundary ratio | Text failures |
|---|---:|---:|---:|
| Light | **5.8339:1** | **3.1942:1** | 0 |
| Dark | **8.8157:1** | **4.3511:1** | 0 |

Lowest ratio overall: **3.1942:1**, a UI boundary, above its 3:1 threshold. Lowest text: **5.8339:1**, hero description in light mode. These values were consistent at all seven widths.

## Implementation constraints

- No `!important` rules added. Legacy overriding stylesheets are retired, not layered underneath the fixes.
- No per-record CSS or per-element color patches. Theme colors are defined in token blocks; artwork has its separate token palette.
- Django models, admin controls, paths, content, résumé/PDF generation and studio persistence remain.
- Removed boot screen, HUD/levels, stickers, command palette, audio, toasts, spark game, Constellation Recall and suspicious-sticker Easter egg. Related backend data structures were preserved for compatibility.
- External certificate availability still depends on the image host; failure now has a readable fallback rather than a blank box.
